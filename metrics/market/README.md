# Données marché

Exports data.ai (Sensor Tower) déposés par Hugo, en attendant un accès API ou MCP.

## Convention de nommage

`AAAA-MM-JJ_<store>_<pays>_<catégorie>_<métrique>.csv`

Exemples :
- `2026-09-28_googleplay_us_puzzle_downloads.csv`
- `2026-09-28_ios_us_simulation_revenue.csv`

## Export attendu chaque semaine

- Top charts US, 90 derniers jours
- Téléchargements et revenus
- Catégories : Puzzle, Simulation, Casual
- iOS et Google Play

Ne jamais modifier un fichier déposé ici. Un nouvel export crée un nouveau fichier.
